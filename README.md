# 🎬 ربات تلگرام مدیا دانلودر (نسخه ساده و رایگان)
> **Simple Media Downloader Telegram Bot** 
> سورس کد رایگان و متن باز ارائه شده توسط وب سایت [سورسیو (sourcio.ir)](https://sourcio.ir)

ربات تلگرام دانلود هوشمند از محبوب ترین شبکه های اجتماعی با معماری مدرن تابعی (Functional Architecture)، بسیار سبک، پرسرعت و بدون وابستگی های پیچیده.

---

## ✨ قابلیت ها و پلتفرم های تحت پوشش

- 📸 **اینستاگرام (Instagram):** دانلود انواع پست ها، ریلزها (Reels)، استوری ها و IGTV
- 🎥 **یوتیوب (YouTube):** دانلود ویدیوهای عادی و بخش شورتز (Shorts) با استریم مستقیم و پرسرعت
- 🎵 **تیک تاک (TikTok):** دانلود ویدیوهای تیک تاک بدون هیچ گونه واتر مارک
- 🐦 **توییتر / ایکس (Twitter / X):** دریافت ویدیوها و گیف های باکیفیت توییت ها
- 📌 **پینترست (Pinterest):** دریافت تصاویر و ویدیوهای پین ها با بالاترین رزولوشن
- 🧵 **تردز (Threads):** دانلود ویدیوها و تصاویر پست های تردز
- 👾 **ردیت (Reddit):** دانلود ویدیوهای ردیت همراه با صدای کامل

---

## ⚙️ امکانات پنل مدیریت و سیستم محدودیت ها

- 📊 **آمار و گزارش پیشرفته سیستم:**
 - تعداد کاربران ثبت نام شده (امروز، دیروز، ۷ روز گذشته، ۳۰ روز گذشته و کل)
 - تعداد گروه های فعال
 - تفکیک کل دانلودها بر اساس تک تک پلتفرم ها (اینستاگرام، یوتیوب، تیک تاک و ...)
 - گزارش زنده وضعیت صف پردازش (کارهای در انتظار، در حال انجام، موفق و ناموفق)
- 🔒 **کنترل سهمیه دانلود روزانه (Quotas):**
 - فعال یا غیرفعال کردن محدودیت دانلود روزانه کاربران عادی با ۱ کلیک
 - تعیین عدد سقف دانلود روزانه برای کاربران (مثلا ۱۰ دانلود در روز)
 - فعال یا غیرفعال کردن محدودیت دانلود روزانه در سوپرگروه ها
 - تعیین سقف دانلود روزانه برای گروه ها (مثلا ۵۰ دانلود در روز)
- 👥 **پشتیبانی کامل از گروه ها:**
 - امکان افزودن ربات به گروه ها جهت دانلود آسان و همگانی مدیا
 - کول داون (فاصله زمانی) ضداسپم برای جلوگیری از شلوغی گروه

## 🛠 پیش نیازها

- **سیستم عامل:** لینوکس (اوبونتو / دبیان) یا مک / ویندوز
- **پایتون:** نسخه 3.10 یا بالاتر
- **ابزار FFmpeg:** جهت فشرده سازی ویدیوها و استخراج صوت

نصب ابزارهای مورد نیاز روی اوبونتو/دبیان:
```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip ffmpeg
```

## 🚀 راهنمای نصب و راه اندازی سریع

### ۱. کلون کردن سورس پروژه
```bash
git clone https://github.com/ArianChaghazardi/simple-media-downloader-bot.git
cd simple-media-downloader-bot
```

### ۲. ساخت محیط مجازی (Virtual Environment)
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی (`.env`)
فایل نمونه را کپی کنید:
```bash
cp .env.example .env
```
فایل `.env` را با ویرایشگر باز کرده و اطلاعات ربات خود را وارد کنید:
```env
# توکن دریافتی از BotFather
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ_1234567
BOT_USERNAME=my_downloader_bot

# شناسه عددی تلگرام ادمین (دریافت از طریق ربات userinfobot@)
ADMIN_IDS=123456789

# دیتابیس پیش فرض اس کیو لایت (نیاز به نصب هیچ دیتابیس جداگانه ای ندارد)
DATABASE_URL=sqlite:///data/bot.db

# سهمیه های دانلود پیش فرض
USER_LIMIT_ENABLED=true
DAILY_USER_DOWNLOAD_LIMIT=10
GROUP_LIMIT_ENABLED=true
DAILY_GROUP_DOWNLOAD_LIMIT=50
```

### ۴. بررسی سلامت سیستم
با دستور زیر از سلامت دیتابیس و توکن مطمئن شوید:
```bash
python -m src.media_bot.cli doctor
```

### ۵. اجرای ربات
برای تست سریع و اجرای هم زمان پولر و ورکر در یک دستور:
```bash
python -m src.media_bot.cli all
```

## 🔄 راه اندازی دائمی در پس زمینه با Systemd (روی سرور لینوکس)

برای اجرای مطمئن و ۲۴ ساعته ربات، می توانید از سرویس های آماده موجود در پوشه `deploy/systemd/` استفاده کنید:

```bash
# کپی فایل سرویس
sudo cp deploy/systemd/simple-media-all.service /etc/systemd/system/

# ویرایش مسیر WorkingDirectory و ExecStart متناسب با مسیر پروژه در سرور
sudo nano /etc/systemd/system/simple-media-all.service

# فعال سازی و استارت سرویس
sudo systemctl daemon-reload
sudo systemctl enable simple-media-all
sudo systemctl start simple-media-all

# مشاهده وضعیت لاگ
journalctl -u simple-media-all -f
```
